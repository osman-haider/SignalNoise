Signal/Noise

A small hybrid search prototype: type an ambiguous term like navy or strike and compare plain keyword search against disambiguation-aware hybrid search on the same query.

All ~100 documents in this corpus are synthetic and self-authored for this demo — nothing here is real customer data, real news content, or an observed complaint about any specific product.

Why these results

Evaluation harness

Runs the full curated test query set (ambiguous terms + a few already-unambiguous control queries) through both modes and compares Precision@10, Recall@10, and NDCG@10 against hand-labeled ground truth.

Signal/Noise — a small, self-contained proof-of-concept built to demonstrate hybrid search + IR evaluation. Not affiliated with, and not a claim about, any specific company's production system.
